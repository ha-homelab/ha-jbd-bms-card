# Security

The card renders existing Home Assistant states and opens HA more-info dialogs. It does not send device commands or make external network requests. User text is escaped before rendering; missing data never becomes a synthetic zero.

Report suspected vulnerabilities privately using the repository's GitHub private vulnerability reporting feature. Do not include Home Assistant tokens, private hostnames or entity registries in public issues. Only the current release is maintained; update before reporting an issue that has already been corrected.

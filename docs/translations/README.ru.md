# JBD Battery & Cell Card — Русский

[Языки](README.md) · [Полная документация на английском](../../README.md)

Карточка Home Assistant только для просмотра: заряд, напряжение батареи, ток, мощность, температура и напряжение каждой ячейки. Она работает с существующими числовыми сущностями; Victron и Cerbo GX не требуются. Для поддержки всех 24 языков интерфейса нужна версия 0.2.0 или новее. Проверяйте примечания к опубликованному выпуску: документация разрабатываемой версии может описывать код, который ещё не вошёл в последний выпуск.

## Установка и настройка

В HACS добавьте `https://github.com/ha-homelab/ha-jbd-bms-card` как **пользовательский репозиторий (custom repository)** с типом **Dashboard** и скачайте нужный выпуск. Карточка пока не включена в стандартный каталог. Если HACS не зарегистрировал модуль JavaScript автоматически, добавьте его:

```text
/hacsfiles/ha-jbd-bms-card/ha-jbd-bms-card.js
```

Для ручной установки скопируйте `ha-jbd-bms-card.js` из выпуска в `/config/www/` и зарегистрируйте `/local/ha-jbd-bms-card.js` как модуль JavaScript. Оставьте только один URL ресурса, затем перезагрузите страницу в браузере. Замена ранее установленной вручную копии описана в разделе [HACS, обновления и переход с ручной установки](../hacs.md).

Добавьте карточку Manual. Замените каждый пример идентификатора сущности на фактический ID из раздела Home Assistant **Инструменты разработчика → Состояния (Developer Tools → States)**:

```yaml
type: custom:ha-jbd-bms-card
language: auto
batteries:
  - name: Battery 1
    soc: sensor.my_battery_soc
    voltage: sensor.my_battery_voltage
    current: sensor.my_battery_current
    power: sensor.my_battery_power
    temperature: sensor.my_battery_temperature
    cells:
      - sensor.my_battery_cell_1
      - sensor.my_battery_cell_2
      - sensor.my_battery_cell_3
      - sensor.my_battery_cell_4
```

Для каждой следующей батареи добавьте ещё один элемент списка. SOC, напряжение батареи и список ячеек обязательны; остальные измерения можно не указывать. Выбирайте ячейки, принадлежащие одной BMS и одному устройству мониторинга. Нажатие на значение открывает его историю или сведения в HA и не отправляет команду батарее.

## Язык

Не указывайте `language` или задайте `language: auto`, чтобы использовать язык профиля Home Assistant. Значение `language: ru` закрепляет русский язык для этой карточки. Региональные языковые теги распознаются, а для неподдерживаемых языков используется английский. Ваши собственные названия и идентификаторы сущностей не переводятся. Все словари включены в карточку; обращения к сервисам перевода не выполняются. Подробнее: [выбор языка](../i18n.md).

## ESPHome и качество измерений

Следуйте [руководству по развёртыванию ESPHome](../esphome-deployment.md) и документации [проекта прошивки](https://github.com/victron-venus/esphome-jbd-bms-mqtt). Каждый поддерживаемый профиль рассчитан на **четыре BMS с четырьмя ячейками в каждой**. Настройте адреса Bluetooth, Wi-Fi и брокер MQTT, сохраняя эти данные приватными, затем добавьте интеграцию MQTT или ESPHome в HA. Установка карточки не прошивает ESP32 и не создаёт сущности батарей.

Отсутствующие показания остаются отсутствующими. Карточка рассчитывает разницу между максимальным и минимальным напряжением ячеек только тогда, когда все настроенные ячейки имеют допустимые значения. Цвета обозначают пороги отображения, а не настройки защиты BMS. Сохранённые значения MQTT и активное соединение не доказывают актуальность измерений; при необходимости настройте срок действия данных на стороне источника. См. [настройку и актуальность данных](../configuration.md) и отдельную [оценку возможности использования Echo Dot](../echo-dot-bluetooth.md).

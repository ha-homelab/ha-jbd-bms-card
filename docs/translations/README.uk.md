# JBD Battery & Cell Card — Українська

[Мови](README.md) · [Повна документація англійською](../../README.md)

Картка Home Assistant лише для перегляду: заряд, напруга акумуляторної батареї, струм, потужність, температура та напруга кожної комірки. Вона працює з наявними числовими сутностями; Victron і Cerbo GX не потрібні. Для підтримки всіх 24 мов інтерфейсу потрібна версія 0.2.0 або новіша. Перевіряйте примітки до опублікованого випуску: документація версії в розробці може описувати код, новіший за останній випуск.

## Встановлення та налаштування

У HACS додайте `https://github.com/ha-homelab/ha-jbd-bms-card` як **користувацький репозиторій (custom repository)** типу **Dashboard** і завантажте потрібний випуск. Картку ще не включено до стандартного каталогу. Якщо HACS не зареєстрував цей модуль JavaScript автоматично, додайте його:

```text
/hacsfiles/ha-jbd-bms-card/ha-jbd-bms-card.js
```

Для встановлення вручну скопіюйте `ha-jbd-bms-card.js` із випуску до `/config/www/` та зареєструйте `/local/ha-jbd-bms-card.js` як модуль JavaScript. Залиште лише один URL ресурсу, а потім перезавантажте сторінку в браузері. Заміну раніше встановленої вручну копії описано в розділі [HACS, оновлення та перехід із ручного встановлення](../hacs.md).

Додайте картку Manual. Замініть кожен приклад ідентифікатора сутності на фактичний ID із розділу Home Assistant **Інструменти розробника → Стани (Developer Tools → States)**:

```yaml
type: custom:ha-jbd-bms-card
language: auto
batteries:
  - name: Battery 1
    soc: sensor.my_battery_soc
    voltage: sensor.my_battery_voltage
    current: sensor.my_battery_current
    power: sensor.my_battery_power
    temperature: sensor.my_battery_temperature
    cells:
      - sensor.my_battery_cell_1
      - sensor.my_battery_cell_2
      - sensor.my_battery_cell_3
      - sensor.my_battery_cell_4
```

Для кожної наступної батареї додайте ще один елемент списку. SOC, напруга батареї та список комірок обов’язкові; решта вимірювань необов’язкова. Обирайте комірки, що належать одній BMS і одному пристрою моніторингу. Натискання на значення відкриває його історію або відомості в HA та не надсилає команди батареї.

## Мова

Пропустіть `language` або вкажіть `language: auto`, щоб використовувати мову профілю Home Assistant. Значення `language: uk` закріплює українську мову для цієї картки. Регіональні мовні теги розпізнаються, а для непідтримуваних мов використовується англійська. Ваші власні назви та ідентифікатори сутностей не перекладаються. Усі словники включені до картки; звернень до сервісів перекладу немає. Докладніше: [вибір мови](../i18n.md).

## ESPHome та якість вимірювань

Дотримуйтеся [посібника з розгортання ESPHome](../esphome-deployment.md) і документації [проєкту прошивки](https://github.com/victron-venus/esphome-jbd-bms-mqtt). Кожен підтримуваний профіль розрахований на **чотири BMS із чотирма комірками в кожній**. Налаштуйте адреси Bluetooth, Wi-Fi та брокер MQTT, зберігаючи ці дані приватними, а потім додайте інтеграцію MQTT або ESPHome до HA. Встановлення картки не прошиває ESP32 і не створює сутності батарей.

Відсутні показання залишаються відсутніми. Картка обчислює різницю між найбільшою та найменшою напругою комірок лише тоді, коли всі налаштовані комірки мають дійсні значення. Кольори позначають пороги відображення, а не налаштування захисту BMS. Збережені значення MQTT та активне з’єднання не підтверджують актуальність вимірювань; за потреби налаштуйте строк дії даних на стороні джерела. Див. [налаштування й актуальність даних](../configuration.md) та окрему [оцінку можливості використання Echo Dot](../echo-dot-bluetooth.md).

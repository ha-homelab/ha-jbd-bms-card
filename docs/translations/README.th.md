# JBD Battery & Cell Card — ไทย

[ภาษา](README.md) · [เอกสารฉบับเต็มภาษาอังกฤษ](../../README.md)

การ์ด Home Assistant แบบอ่านอย่างเดียวสำหรับแสดงระดับประจุ แรงดันแพ็กแบตเตอรี่ กระแส กำลังไฟ อุณหภูมิ และแรงดันของแต่ละเซลล์ ใช้งานกับเอนทิตีตัวเลขที่มีอยู่แล้ว โดยไม่จำเป็นต้องมี Victron หรือ Cerbo GX การรองรับภาษาอินเทอร์เฟซครบทั้ง 24 ภาษาต้องใช้เวอร์ชัน 0.2.0 ขึ้นไป โปรดตรวจสอบบันทึกของรุ่นที่เผยแพร่ เพราะเอกสารระหว่างการพัฒนาอาจอธิบายโค้ดที่ใหม่กว่ารุ่นล่าสุดที่เผยแพร่แล้ว

## การติดตั้งและตั้งค่า

ใน HACS ให้เพิ่ม `https://github.com/ha-homelab/ha-jbd-bms-card` เป็น **คลังแบบกำหนดเอง (custom repository)** เลือกประเภท **Dashboard** แล้วดาวน์โหลดรุ่นที่ต้องการ การ์ดยังไม่อยู่ในแค็ตตาล็อกเริ่มต้น หาก HACS ยังไม่ได้ลงทะเบียนโมดูล JavaScript นี้ ให้ลงทะเบียนด้วยตนเอง:

```text
/hacsfiles/ha-jbd-bms-card/ha-jbd-bms-card.js
```

หากติดตั้งด้วยตนเอง ให้คัดลอก `ha-jbd-bms-card.js` จากรุ่นที่เผยแพร่ไปยัง `/config/www/` แล้วลงทะเบียน `/local/ha-jbd-bms-card.js` เป็นโมดูล JavaScript ใช้ URL ของทรัพยากรเพียงรายการเดียว จากนั้นโหลดเบราว์เซอร์ใหม่ ดูวิธีแทนที่สำเนาที่เคยติดตั้งด้วยตนเองใน [HACS การอัปเดต และการย้ายการติดตั้ง](../hacs.md)

เพิ่มการ์ด Manual แล้วแทนที่ entity ID ทุกตัวในตัวอย่างด้วย ID จริงจาก **เครื่องมือสำหรับนักพัฒนา → สถานะ (Developer Tools → States)** ของ Home Assistant:

```yaml
type: custom:ha-jbd-bms-card
language: auto
batteries:
  - name: Battery 1
    soc: sensor.my_battery_soc
    voltage: sensor.my_battery_voltage
    current: sensor.my_battery_current
    power: sensor.my_battery_power
    temperature: sensor.my_battery_temperature
    cells:
      - sensor.my_battery_cell_1
      - sensor.my_battery_cell_2
      - sensor.my_battery_cell_3
      - sensor.my_battery_cell_4
```

เพิ่มรายการใหม่สำหรับแบตเตอรี่แต่ละลูก ต้องระบุ SOC แรงดันแพ็ก และรายการเซลล์ ส่วนค่าการวัดอื่นเป็นตัวเลือก เลือกเซลล์ที่อยู่ใน BMS และอุปกรณ์ตรวจวัดเดียวกัน การแตะค่าจะเปิดประวัติหรือรายละเอียดใน HA โดยไม่ส่งคำสั่งไปยังแบตเตอรี่

## ภาษา

ละ `language` ไว้หรือใช้ `language: auto` เพื่อใช้ภาษาตามโปรไฟล์ Home Assistant ใช้ `language: th` หากต้องการกำหนดให้การ์ดนี้ใช้ภาษาไทย ระบบรองรับการจับคู่แท็กภาษาตามภูมิภาค และจะใช้ภาษาอังกฤษเมื่อไม่รองรับภาษาที่เลือก ชื่อที่คุณตั้งเองและ entity ID จะไม่ถูกแปล พจนานุกรมทั้งหมดรวมอยู่ในตัวการ์ด จึงไม่มีการติดต่อบริการแปลภาษา ดู [การเลือกภาษา](../i18n.md)

## ESPHome และคุณภาพการวัด

ทำตาม [คู่มือการติดตั้งใช้งาน ESPHome](../esphome-deployment.md) และ [โครงการเฟิร์มแวร์](https://github.com/victron-venus/esphome-jbd-bms-mqtt) โปรไฟล์ที่โครงการดูแลแต่ละชุดออกแบบมาสำหรับ **BMS สี่ตัว โดยแต่ละตัวมีสี่เซลล์** ตั้งค่าที่อยู่ Bluetooth, Wi-Fi และ MQTT broker โดยเก็บข้อมูลเหล่านี้เป็นส่วนตัว แล้วเพิ่มการเชื่อมต่อ MQTT หรือ ESPHome ใน HA การติดตั้งการ์ดนี้ไม่ได้แฟลช ESP32 หรือสร้างเอนทิตีแบตเตอรี่

ค่าที่ขาดหายไปจะแสดงว่าไม่มีข้อมูลเช่นเดิม การ์ดจะคำนวณผลต่างระหว่างแรงดันเซลล์สูงสุดและต่ำสุดก็ต่อเมื่อเซลล์ทุกตัวที่ตั้งค่าไว้มีค่าที่ใช้ได้ สีเป็นเพียงเกณฑ์สำหรับการแสดงผล ไม่ใช่การตั้งค่าป้องกันของ BMS ค่า MQTT ที่เก็บค้างไว้และสถานะออนไลน์ไม่ได้ยืนยันว่าการวัดเป็นข้อมูลล่าสุด หากจำเป็น ให้กำหนดอายุข้อมูลที่แหล่งต้นทาง ดู [การตั้งค่าและความใหม่ของข้อมูล](../configuration.md) และเอกสารแยก [การประเมินความเป็นไปได้ในการใช้ Echo Dot](../echo-dot-bluetooth.md)

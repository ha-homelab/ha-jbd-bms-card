# JBD Battery & Cell Card — বাংলা

[ভাষাসমূহ](README.md) · [সম্পূর্ণ ইংরেজি নথি](../../README.md)

Home Assistant-এর এই কার্ড শুধু তথ্য দেখায়: চার্জের অবস্থা, ব্যাটারি প্যাকের ভোল্টেজ, কারেন্ট, শক্তি, তাপমাত্রা এবং প্রতিটি সেলের ভোল্টেজ। এটি বিদ্যমান সংখ্যামূলক এনটিটির সঙ্গে কাজ করে; Victron বা Cerbo GX লাগে না। ইন্টারফেসের সব ২৪টি ভাষার জন্য 0.2.0 বা পরবর্তী সংস্করণ দরকার। প্রকাশিত সংস্করণের নোট দেখুন; উন্নয়ন চলাকালীন নথিতে সর্বশেষ প্রকাশিত সংস্করণের চেয়ে নতুন কোডের বর্ণনা থাকতে পারে।

## ইনস্টল ও কনফিগার করুন

HACS-এ `https://github.com/ha-homelab/ha-jbd-bms-card` ঠিকানাটি **custom repository** হিসেবে যোগ করুন, ধরন হিসেবে **Dashboard** বেছে নিন এবং কাঙ্ক্ষিত সংস্করণ ডাউনলোড করুন। কার্ডটি এখনও ডিফল্ট ক্যাটালগে নেই। HACS নিজে যোগ না করলে এই JavaScript module নিবন্ধন করুন:

```text
/hacsfiles/ha-jbd-bms-card/ha-jbd-bms-card.js
```

ম্যানুয়াল ইনস্টলের জন্য প্রকাশিত সংস্করণের `ha-jbd-bms-card.js` ফাইলটি `/config/www/`-এ কপি করুন এবং `/local/ha-jbd-bms-card.js`-কে JavaScript module হিসেবে নিবন্ধন করুন। শুধু একটি resource URL রাখুন, তারপর ব্রাউজার রিলোড করুন। আগে ম্যানুয়ালি ইনস্টল করা কপি বদলাতে [HACS, আপডেট ও স্থানান্তর](../hacs.md) দেখুন।

একটি Manual কার্ড যোগ করুন। উদাহরণের প্রতিটি entity ID-এর জায়গায় Home Assistant-এর **Developer Tools → States** থেকে পাওয়া আসল ID বসান:

```yaml
type: custom:ha-jbd-bms-card
language: auto
batteries:
  - name: Battery 1
    soc: sensor.my_battery_soc
    voltage: sensor.my_battery_voltage
    current: sensor.my_battery_current
    power: sensor.my_battery_power
    temperature: sensor.my_battery_temperature
    cells:
      - sensor.my_battery_cell_1
      - sensor.my_battery_cell_2
      - sensor.my_battery_cell_3
      - sensor.my_battery_cell_4
```

প্রতিটি ব্যাটারির জন্য তালিকায় আরেকটি আইটেম যোগ করুন। SOC, প্যাক ভোল্টেজ ও সেলের তালিকা আবশ্যক; অন্য পরিমাপগুলো ঐচ্ছিক। একই BMS ও মনিটরের অন্তর্গত সেল বেছে নিন। কোনো মানে চাপ দিলে HA-তে তার ইতিহাস বা বিস্তারিত খোলে; ব্যাটারিতে কোনো নির্দেশ পাঠানো হয় না।

## ভাষা

Home Assistant প্রোফাইলের ভাষা অনুসরণ করতে `language` বাদ দিন অথবা `language: auto` ব্যবহার করুন। এই কার্ডের ভাষা নির্দিষ্টভাবে বাংলা করতে `language: bn` দিন। আঞ্চলিক ভাষা ট্যাগ শনাক্ত করা হয় এবং অসমর্থিত ভাষার ক্ষেত্রে ইংরেজি ব্যবহার হয়। আপনার দেওয়া নাম ও entity ID কখনো অনুবাদ করা হয় না। সব অনুবাদ কার্ডের সঙ্গে অন্তর্ভুক্ত থাকে; কোনো অনুবাদ সেবার সঙ্গে যোগাযোগ করা হয় না। [ভাষা নির্বাচন](../i18n.md) দেখুন।

## ESPHome ও পরিমাপের মান

[ESPHome স্থাপন নির্দেশিকা](../esphome-deployment.md) ও [ফার্মওয়্যার প্রকল্প](https://github.com/victron-venus/esphome-jbd-bms-mqtt) অনুসরণ করুন। প্রকল্পের রক্ষণাবেক্ষণ করা প্রতিটি প্রোফাইল **চারটি BMS, প্রতিটিতে চারটি সেল** ধরে তৈরি। Bluetooth ঠিকানা, Wi-Fi ও MQTT broker ব্যক্তিগতভাবে কনফিগার করুন, তারপর HA-তে MQTT বা ESPHome integration যোগ করুন। এই কার্ড ইনস্টল করলে ESP32 ফ্ল্যাশ হয় না বা ব্যাটারির এনটিটি তৈরি হয় না।

অনুপস্থিত মানকে অনুপস্থিত হিসেবেই দেখানো হয়। কনফিগার করা সব সেলের মান বৈধ হলেই কার্ডটি সর্বোচ্চ ও সর্বনিম্ন সেল ভোল্টেজের পার্থক্য গণনা করে। রঙগুলো প্রদর্শনের সীমা নির্দেশ করে, BMS-এর সুরক্ষা সেটিং নয়। MQTT-তে ধরে রাখা মান এবং অনলাইন সংযোগ পরিমাপের সাম্প্রতিকতা প্রমাণ করে না; প্রয়োজনমতো তথ্যের উৎসে মেয়াদ শেষ হওয়ার ব্যবস্থা করুন। [কনফিগারেশন ও তথ্যের সাম্প্রতিকতা](../configuration.md) এবং পৃথক [Echo Dot ব্যবহারের সম্ভাব্যতা মূল্যায়ন](../echo-dot-bluetooth.md) দেখুন।

## Виртуальные последовательные сборки

Новая модель `virtual_batteries` объединяет физические батареи одной последовательной сборки и сохраняет отображение всех их ячеек. Напряжения складываются; ток и Ah не складываются, SOC не усредняется. Подробности на английском: [модель данных](virtual-batteries.md), [примеры](../examples/README.md), [ранбук](runbook.md), [устранение неполадок](troubleshooting.md). Функции нет в 0.2.0-beta.1; нужен выпуск, явно включающий её.

# Карточка батарей JBD и отдельных ячеек

Красочная карточка Home Assistant: заряд каждой батареи, напряжение, ток, мощность, температура, напряжения отдельных ячеек и их разброс. Поддерживает несколько цепочек, светлую и тёмную темы, мобильный экран. Victron, Cerbo GX и Venus OS не нужны.

## Установка

В HACS добавьте **пользовательский репозиторий** `https://github.com/ha-homelab/ha-jbd-bms-card`, категория **Dashboard**, и скачайте карточку. Если ресурс не добавился автоматически, добавьте `/hacsfiles/ha-jbd-bms-card/ha-jbd-bms-card.js` как JavaScript module.

Либо скопируйте `ha-jbd-bms-card.js` в `/config/www/`, затем добавьте ресурс `/local/ha-jbd-bms-card.js?v=0.1.0` типа JavaScript module. Обновите страницу браузера. Если `/config/www` уже существует, перезапуск HA не нужен; если создаёте каталог впервые, один раз перезапустите HA для обслуживания `/local/`.

В редакторе панели добавьте ручную карточку и укажите **реальные ID сущностей** из «Инструменты разработчика → Состояния»:

```yaml
type: custom:ha-jbd-bms-card
title: Батарейная
language: ru
batteries:
  - name: Батарея 1
    subtitle: Цепочка 1 · LiFePO₄
    soc: sensor.my_battery_soc
    voltage: sensor.my_battery_voltage
    current: sensor.my_battery_current
    power: sensor.my_battery_power
    temperature: sensor.my_battery_temperature
    cells:
      - sensor.my_battery_cell_1
      - sensor.my_battery_cell_2
      - sensor.my_battery_cell_3
      - sensor.my_battery_cell_4
```

Названия в примере условные. Добавляйте батареи отдельными элементами списка `batteries`. Карточка сама выбирает число колонок по доступной ширине. Для восьми батарей удобен полноширинный вид панели Panel. В обеих ESPHome-цепочках локальная нумерация BMS — 1–4; фактические ID Home Assistant определяются обнаружением и реестром.

## Показания и цвета

Неизвестные или недоступные значения показываются прочерком. Нулевой заряд, нулевой ток и отрицательные показания тока сохраняются. Если отсутствует хотя бы одна ячейка, разброс и min/max не вычисляются. Нажатие на значение открывает стандартное окно подробностей HA; команд батарее карточка не отправляет.

Пороговые цвета — только оформление. По умолчанию диапазон ячеек 2,8–3,65 В, жёлтый разброс от 30 мВ и красный от 80 мВ, низкий заряд до 15%, предупреждение до 30%. Настройте диапазоны под вашу химию. Полоса напряжения ячейки не является оценкой её заряда, а параметры карточки не меняют настройки защиты BMS.

«Сущности доступны» не доказывает свежесть измерения. Retained MQTT может хранить старое значение; `last_changed`/`last_updated` не являются надёжным возрастом измерения. Карточка прямо указывает это внизу. Для строгой проверки свежести нужен отдельный потребитель атомарной телеметрии с истечением срока данных; можно подключить его достоверный сигнал через `availability`.

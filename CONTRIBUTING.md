# Contributing

Use Node.js 22 or newer. Run `npm ci --ignore-scripts`, `npm run check`, `npm test`, `npm run build`, and `node scripts/check-package.mjs`. Keep the root JS module self-contained and use synthetic fixtures only. Open a pull request with the behavior change and validation results.

Verify both light/dark themes, a narrow mobile viewport, keyboard navigation, unavailable data and the complete-cell spread rule. A visible value must never claim freshness that the underlying HA entity does not establish. Keep all physical control commands out of the card. Add tests for behavioral changes, and update the configuration documentation and changelog when applicable.
